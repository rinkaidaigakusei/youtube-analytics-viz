プライバシーポリシー

YouTube Analytics Viz(以下「本アプリ」)は、YouTubeチャンネルの運営者本人が、自分のチャンネルの統計を確認するために使う個人用のツールです。 本アプリは YouTube API サービスを利用しています。

取得する情報

Googleアカウントでログインして許可した場合に限り、そのアカウントのYouTubeチャンネルについて次の情報を取得します。

  • 動画の一覧(タイトル、公開日時、長さ、サムネイル)
  • YouTubeアナリティクスの統計(再生数、再生時間、視聴維持率など)
  • 動画に付いたコメントと、その投稿者の表示名

このほか、公開されている動画の再生数・高評価数・コメント数を定期的に記録しています。

利用目的

取得した情報は、グラフや一覧として画面に表示するためだけに使います。コメントへの返信は、ログインした本人が画面から送信した場合にのみ、そのアカウントとして投稿します。 広告、販売、第三者への提供には使いません。

保存場所と保存期間

取得した情報とログイン情報(アクセストークン)は、本アプリのサーバー(Render)と、その控えを置くデータベース(Neon)に保存します。 これらは表示を速くするための控えで、運営者本人が削除するまで保存されます。

アクセス許可の取り消し

本アプリに与えた許可は、Googleアカウントの「第三者によるアクセス」のページからいつでも取り消せます。

Googleユーザーデータの取り扱い

本アプリによる Google API から受け取った情報の使用と他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー(限定的な使用の要件を含む)に準拠します。
